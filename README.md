# Time Series Forecasting Using LSTM and GRU

## Project Description

This project focuses on time series forecasting using Deep Learning techniques, particularly Long Short-Term Memory (LSTM) and Gated Recurrent Unit (GRU) neural networks.

The main objective of this project is to analyze sequential data, identify temporal patterns, and predict future values based on historical observations.

LSTM and GRU are types of Recurrent Neural Networks (RNN) designed to process sequential data and learn dependencies over time.

## Objectives

- Understand the principles of time series forecasting.
- Explore and preprocess time series data.
- Build LSTM and GRU neural network models.
- Train models using historical data.
- Evaluate model performance.
- Compare the forecasting capabilities of LSTM and GRU.

## Models Used

### LSTM (Long Short-Term Memory)

LSTM is a type of recurrent neural network that uses memory cells and gates to learn long-term dependencies in sequential data.

### GRU (Gated Recurrent Unit)

GRU is another recurrent neural network architecture that uses update and reset gates to process sequential information. It has a simpler structure compared to LSTM.

## Project Structure

## Results

The project demonstrates the application of LSTM and GRU neural networks for time series forecasting.

The performance of both models can be analyzed and compared using the evaluation results obtained during the experiments.

## Conclusion

This project provides practical experience in working with time series data and applying deep learning models for forecasting.

It demonstrates how recurrent neural networks such as LSTM and GRU can be used to identify patterns in sequential data and predict future values.
